# Test fixtures

These are small, hand-written format examples. They are safe to keep in the
repository and are not experimental results.

- `initial_judge_example.txt`: input format accepted by `run_evaluator.py`.
- `evaluator_example.txt`: LAJ text report accepted by `convert_evaluator_txt_to_sft.py`.
- `fine_tuned_judge_example.txt`: output format produced when using a LoRA adapter with `run_initial_judge.py`.
